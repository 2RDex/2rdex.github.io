2RD Verify

ระบบยืนยันตัวตนการติดตามช่อง 2RD Channel

2RD Channel Subscription Verification

📌 วัตถุประสงค์ของระบบ

📌 Application Purpose

2RD Verify คือระบบตรวจสอบการกดติดตามช่อง 2RD Channel เพื่อรับยศใน Discord Server โดยอัตโนมัติ

2RD Verify automatically checks your 2RD Channel YouTube subscription to assign roles in our Discord Server.

⚙️ ขั้นตอนการทำงาน

⚙️ How It Works

  1. กดปุ่ม "เริ่มต้นยืนยันตัวตน" และเข้าสู่ระบบด้วย Discord
  2. เข้าสู่ระบบด้วย Google และอนุมัติสิทธิ์อ่านข้อมูลการติดตาม (Read-only)
  3. 2RD Verify ตรวจสอบสถานะการติดตามผ่าน YouTube Data API
  4. หากยืนยันเรียบร้อยระบบจะมอบยศ Discord ให้อัตโนมัติ
  1. Click the "Start identity verification" button and log in with Discord.
  2. Sign in with Google and authorize YouTube read-only permission.
  3. 2RD Verify checks the subscription status using YouTube Data API.
  4. If confirmed, the corresponding Discord role is assigned automatically.
