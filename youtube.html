YT Sub Checker

YouTube Subscription Verification

📌 Application Purpose

YT Sub Checker is a verification service that checks whether a user's YouTube account is subscribed to the configured YouTube channel.

After successful verification, the service can assign the corresponding role to the user's Discord account.

⚙️ How It Works

  1. Sign in with Discord.
  2. Choose to verify your YouTube subscription.
  3. Sign in with Google and authorize the requested YouTube read-only permission.
  4. YT Sub Checker checks the subscription status using the YouTube Data API.
  5. If the subscription is confirmed, the corresponding Discord role is assigned.

🔒 Google & YouTube Data

YT Sub Checker uses Google OAuth 2.0 and requests the youtube.readonly permission only for the purpose of verifying the user's YouTube subscription status.

  • The application does not request your Google password.
  • YouTube data is used only for subscription verification.
  • The application does not use YouTube data for advertising.
  • The application does not sell Google or YouTube data.
