2RD Verify

ระบบยืนยันตัวตนการติดตามช่อง YouTube

YouTube Subscription Verification

📌 วัตถุประสงค์ของระบบ

📌 Application Purpose

2RD Verify คือบริการยืนยันตัวตนสำหรับตรวจสอบว่าบัญชี YouTube ของผู้ใช้ได้กดติดตามช่อง YouTube ที่กำหนดไว้หรือไม่

เมื่อทำการยืนยันตัวตนสำเร็จ ระบบจะมอบยศที่เกี่ยวข้องให้กับบัญชี Discord ของผู้ใช้โดยอัตโนมัติ

2RD Verify is a verification service that checks whether a user's YouTube account is subscribed to the configured YouTube channel.

After successful verification, the service assigns the corresponding role to the user's Discord account.

⚙️ ขั้นตอนการทำงาน

⚙️ How It Works

  1. เข้าสู่ระบบด้วย Discord
  2. เลือกยืนยันการกดติดตามช่อง YouTube
  3. เข้าสู่ระบบด้วย Google และอนุมัติสิทธิ์อ่านข้อมูลการติดตาม (Read-only)
  4. 2RD Verify ตรวจสอบสถานะการติดตามผ่าน YouTube Data API
  5. หากยืนยันเรียบร้อย ระบบจะมอบยศ Discord ให้อัตโนมัติ
  1. Sign in with Discord.
  2. Choose to verify your YouTube subscription.
  3. Sign in with Google and authorize the requested YouTube read-only permission.
  4. 2RD Verify checks the subscription status using the YouTube Data API.
  5. If confirmed, the corresponding Discord role is assigned.

🔒 การจัดการข้อมูล Google & YouTube

🔒 Google & YouTube Data

2RD Verify ใช้งาน Google OAuth 2.0 โดยขอสิทธิ์ youtube.readonly เฉพาะเพื่อตรวจสอบสถานะการติดตามช่องเท่านั้น

  • ระบบไม่มีการขอรหัสผ่าน Google ของคุณ
  • ข้อมูล YouTube ถูกใช้เพื่อการยืนยันตัวตนเท่านั้น
  • ไม่มีการนำข้อมูลไปใช้เพื่อการโฆษณา
  • ไม่มีการขายหรือส่งต่อข้อมูล Google/YouTube ให้บุคคลภายนอก

2RD Verify uses Google OAuth 2.0 and requests the youtube.readonly permission only for verifying subscription status.

  • The application does not request your Google password.
  • YouTube data is used only for subscription verification.
  • The application does not use YouTube data for advertising.
  • The application does not sell Google or YouTube data.
